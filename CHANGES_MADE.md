# Changes Made to Fix Backend Startup Errors

## Problem
Backend was continuously failing to start with error:
```
java.sql.SQLException: Access denied for user 'root'@'localhost' (using password: YES)
```

This was because the application was configured to use MySQL, but MySQL was either not running or had incorrect credentials.

## Solution Overview
Reverted to using **H2 In-Memory Database** for immediate functionality + Fixed H2 dependency scope + Created H2-compatible schema.

---

## Files Modified

### 1. `pom.xml` (Line 39-42)
**Change**: Removed `<scope>test</scope>` from H2 dependency

**Before**:
```xml
<dependency>
    <groupId>com.h2database</groupId>
    <artifactId>h2</artifactId>
    <scope>test</scope>
</dependency>
```

**After**:
```xml
<dependency>
    <groupId>com.h2database</groupId>
    <artifactId>h2</artifactId>
</dependency>
```

**Why**: H2 was only available during test execution. Changed to runtime dependency so main application can use it.

---

### 2. `src/main/resources/application.yml`
**Change**: Replaced MySQL configuration with H2 configuration

**Before**:
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/payment_db?useSSL=false&serverTimezone=UTC&allowPublicKeyRetrieval=true
    driver-class-name: com.mysql.cj.jdbc.Driver
    username: root
    password: nauada!
  sql:
    init:
      mode: always
      platform: mysql
```

**After**:
```yaml
spring:
  datasource:
    url: jdbc:h2:mem:paymentsdb;DB_CLOSE_DELAY=-1;MODE=PostgreSQL
    driver-class-name: org.h2.Driver
    username: sa
    password:
  sql:
    init:
      mode: always
      platform: h2
  h2:
    console:
      enabled: true
```

**Why**: H2 is an in-memory database that requires no external setup, making it perfect for development.

---

### 3. `src/main/resources/schema.sql` (NEW FILE)
**Change**: Created H2-compatible database schema

**Content**:
```sql
CREATE TABLE IF NOT EXISTS payments (
    id VARCHAR(64) PRIMARY KEY,
    idempotency_key VARCHAR(64) NOT NULL UNIQUE,
    source_account VARCHAR(20) NOT NULL,
    destination_account VARCHAR(20) NOT NULL,
    reference VARCHAR(140),
    amount DECIMAL(14, 2) NOT NULL,
    currency VARCHAR(3) NOT NULL,
    status VARCHAR(20) NOT NULL,
    error_code VARCHAR(64),
    error_message VARCHAR(255),
    created_at TIMESTAMP NOT NULL,
    updated_at TIMESTAMP NOT NULL
);

CREATE TABLE IF NOT EXISTS payment_status_history (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    payment_id VARCHAR(64) NOT NULL,
    from_status VARCHAR(20),
    to_status VARCHAR(20) NOT NULL,
    error_code VARCHAR(64),
    error_message VARCHAR(255),
    triggered_by VARCHAR(64) NOT NULL,
    changed_at TIMESTAMP NOT NULL,
    CONSTRAINT fk_history_payment FOREIGN KEY (payment_id) REFERENCES payments(id)
);

CREATE INDEX IF NOT EXISTS idx_payments_status ON payments(status);
CREATE INDEX IF NOT EXISTS idx_history_payment_id ON payment_status_history(payment_id);
```

**Key Differences from MySQL Schema**:
- `BIGINT GENERATED BY DEFAULT AS IDENTITY` instead of `BIGINT AUTO_INCREMENT` (H2 syntax)
- Keeps all column definitions the same for compatibility

**Why**: Spring Boot's `spring.sql.init.mode=always` automatically creates tables on startup using this schema.
