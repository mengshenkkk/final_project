# Backend Status Report

## ✅ Backend Started Successfully!

The Spring Boot Payment Application is now running on **port 8080** with **H2 In-Memory Database**.

### Current Configuration

**Database**: H2 In-Memory  
**URL**: `jdbc:h2:mem:paymentsdb`  
**Server Port**: 8080  
**API Prefix**: `/api/payments`

### Available Endpoints

1. **List Payments** (GET)
   - URL: `http://localhost:8080/api/payments`
   - Optional Query: `?status=CREATED` (filter by status)
   - Example: `curl http://localhost:8080/api/payments`

2. **Get Payment by ID** (GET)
   - URL: `http://localhost:8080/api/payments/{paymentId}`
   - Example: `curl http://localhost:8080/api/payments/PAY-123`

3. **Create Payment** (POST)
   - URL: `http://localhost:8080/api/payments`
   - Body: JSON with sourceAccount, destinationAccount, amount, currency, reference
   - Example:
     ```json
     {
       "sourceAccount": "ACC001",
       "destinationAccount": "ACC002",
       "amount": "100.50",
       "currency": "USD",
       "reference": "Payment for services",
       "idempotencyKey": "unique-key-123"
     }
     ```

4. **Validate Payment** (POST)
   - URL: `http://localhost:8080/api/payments/{paymentId}/validate`

5. **Send Payment** (POST)
   - URL: `http://localhost:8080/api/payments/{paymentId}/send`

6. **Complete Payment** (POST)
   - URL: `http://localhost:8080/api/payments/{paymentId}/complete`

7. **Fail Payment** (POST)
   - URL: `http://localhost:8080/api/payments/{paymentId}/fail`
   - Body: JSON with errorCode and errorMessage
   - Example:
     ```json
     {
       "errorCode": "NETWORK_ERROR",
       "errorMessage": "Connection timeout"
     }
     ```

### Database Details

- **In-Memory H2 Database**: Data is lost when the application restarts
- **Tables Created**:
  - `payments`: Stores payment records
  - `payment_status_history`: Audit trail of all status changes
